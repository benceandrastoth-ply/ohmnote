Free · open source · Windows, Linux, Android

A notebook for electronics.

Draw the schematic, sketch the breadboard, write down what you measured: all on the same page. Then flip through it like a real book.

Download View the source

Everything on one page

Real schematics

45+ parts, wires that snap to pins and follow parts, and real properties: ohms, tolerance, voltage, colour bands, an LED resistor calculator and a parts list.

Your own handwriting

Write the alphabet once and OhmNote turns it into a real font, joined-up cursive (folyóírás) included, with three versions of every letter so it never looks stamped.

Photos → digital book

Photograph your paper notebook. Pages are found, straightened and cleaned like a scanner, shadows and printed lines removed, all on your device.

Read it like a book

Leather, cloth, school-book or circuit-board covers, pages that curl as you turn them, and one-click PDF.

Calculator and formulas

Type 4k7 || 10k or R1 + R2. Ohm's law, dividers, RC, resonance, 555, op-amps, and a cheat sheet of the basic rules.

Make it yours

Notebook, squared paper, blueprint, chalkboard, terminal… 80 settings, fountain pen and pencil nibs, write-in animation, English and Hungarian.

On your phone too

The Android app has a touch layout: tools at the bottom, panels that slide in, pinch to zoom, and palm rejection when you write with a stylus. Sign in and your notebook syncs between all your devices.

pacman · x86_64

Any Linux

Android

Open source

OhmNote is free software under the MIT licence. Read the code, report a bug, suggest a part for the library, or build it yourself:

git clone https://github.com/benceandrastoth-ply/ohmnote.git
cd ohmnote
npm install
npm start            # run it
npm run dist         # Windows installer
npm run dist:linux   # .deb .rpm pacman AppImage
npm run android:debug
